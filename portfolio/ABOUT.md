## Long Version

I am an engineer focused on software engineering, full-stack systems, and practical generative AI. Originally from Patna, Bihar, I moved to Bengaluru for my engineering degree, where I spend my time designing data models, architecting distributed backends, and crafting thoughtful, high-performance web interfaces.

I bridge two worlds: the physical rigor of electronics and communication engineering (microcontrollers, sensor registers, signal sampling, and RTOS fundamentals) with modern full-stack web and applied AI development (Next.js, Node.js/NestJS, PostgreSQL, and LLM reasoning pipelines).

My engineering stance is straightforward: **solve real problems with production durability, not throwaway demos.** In systems like LedgerMind, that means running deterministic financial reconciliation first and using LLMs only to investigate exceptions. In KRAMA OS, it means designing a unified schema for knowledge and execution instead of gluing together disconnected third-party apps.

## What I Value in Engineering

- **End-to-End Ownership**: Caring as much about query efficiency, indexing, and connection pools as I do about visual polish and keyboard navigation.
- **Deterministic Logic First**: Using AI where probabilistic reasoning excels (summarization, fuzzy anomaly explanation, synthesis), but never trusting an LLM with arithmetic, authorization, or uncontrolled production writes.
- **Thoughtful Restraint**: Prioritizing clean typography, fast page loads, and native web primitives over heavy JS animation bloat and neon gimmicks.
- **Continuous Shipping**: Building, testing, and Dockerizing real projects alongside rigorous DSA/LeetCode preparation.
