# Resume

## Source file
`/assets/resume/[your-name]-resume.pdf`

## Display rule
Resume is offered as a direct download from the Contact section and the
nav — not gated behind a form. One click, one file.

## Content parity rule
The resume should not contradict the site. Dates, titles, and stack
listed here must match `EXPERIENCE.md` and `SKILLS.md` exactly — hiring
managers cross-check this.

## Update checklist (do this whenever the resume PDF changes)
- [ ] Dates match `EXPERIENCE.md`
- [ ] Stack matches `SKILLS.md`
- [ ] Contact info matches `CONTACT.md`
- [ ] File name has no spaces, includes your name
- [ ] File size under 1MB
